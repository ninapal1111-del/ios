# French for NCLC 7

The website version of the **French for NCLC 7** study app: a 24-week TCF Canada course from A1 to B2 with the whole book inside, flashcards with sound, interactive exams (54 weekly sets and two full mocks), listening practice, speaking and writing practice, daily goals and progress tracking.

## Use it

- **Laptop:** open the website address.
- **iPhone:** open it in **Safari** → **Share** → **Add to Home Screen**. It opens full-screen like an app and works offline after the first visit. For the French voice: Settings → Accessibility → Spoken Content → Voices → French.
- **Android:** use the APK, or open the website in Chrome → ⋮ → **Install app**.

Progress is saved on each device. Use **Me → Backup** to move it between devices.

## What's in this repo

The built website only (HTML, CSS, JavaScript, icons). It is generated from the app's source in a separate private repository; don't edit these files by hand, as the next update replaces them.

`sw.js` is the service worker that stores the app on the device for offline use.
